## 問題
### 問1
(2)0010 なら、2進数。(n)0010なら、n進数とする。
以下の値を全て10進数にせよ。

・(2)0100
・(2)1010
・(8)1570
・(8)0041
・(16)00AB
・(16)102F

### 問2
2の補数を用いて以下を負の値にせよ。
なお、4bitでの計算とする。

・0001
・1001
・0101
・0111

上記で求めた値に1100足した値を全て求めよ。

### 問3
以下の計算をして、2進数で表記せよ。
尚、bit数は無限とする

・1001 の4倍
・1000 の1/2倍
・1111 の3倍

## 解答
### 問1
(2)0010 なら、2進数。(n)0010なら、n進数とする。
以下の値を全て10進数にせよ。

・(2)0100 = 4
・(2)1010 = 10
・(8)1570 = 512 + 320 + 56 = 888
・(8)0041 = 32 + 1 = 33
・(16)00AB = 160 + 11 = 171 
・(16)102F = 4096 + 32 + 15 = 4143

### 問2
2の補数を用いて以下を負の値にせよ。
なお、4bitでの計算とする。

・0001 = 1111(-1)
・1001 = 0111(-9)
・0101 = 1011(-5)
・0111 = 1001(-7)

上記で求めた値に1100足した値を全て求めよ。

・1111(-1) + 1100(12) = 1011(11)
・0111(-9) + 1100(12) = 0011(3)
・1011(-5) + 1100(12) = 0111(7)
・1001(-7) + 1100(12) = 0101(5)

### 問3
以下の計算をして、2進数で表記せよ。
尚、bit数は無限とする
・1001 の4倍 = 100100
・1000 の1/2倍 = 0100
・1111(15) の3倍 = 1111*(2^1 + 1) = 11110 + 1111 = 101101(45)
