## 中身
- `*.md`：Zenn の編集ページからコピーした原稿。画像のリンクだけ、`images/` を指すように書き換えた（元は `storage.googleapis.com/zenn-user-upload/…`）。数式は Zenn の書き方（`$…$`、`$$…$$`）。
- `images/`：画像。ファイル名は Zenn 上と同じ。
- `html/`：Zenn の表示用 HTML を、ブラウザで見られるようにしたもの（数式は KaTeX で表示。ネット接続が必要）。
- `raw/`：Zenn の API（`/api/books/…`、`/api/chapters/…`）から取った生のデータ（JSON）。

## 保存したときの確認
- 原稿と表示版で、見出しと画像のファイル名が全章で一致した。
- `html/` の数式は全319か所がエラーなく表示された。
