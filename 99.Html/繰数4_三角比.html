覚えるべき三角形の図示

次の各問について、図を描き、辺の長さの比を記入せよ。

  1. $30^\circ-60^\circ-90^\circ$ の直角三角形を図示し、辺の比を記入せよ。
  2. $45^\circ-45^\circ-90^\circ$ の直角三角形を図示し、辺の比を記入せよ。
  3. $30^\circ-60^\circ-90^\circ$ の三角形で、最短辺を$1$とした図を描き、他の$2$辺を記入せよ。
  4. $45^\circ-45^\circ-90^\circ$ の三角形で、斜辺を$1$とした図を描き、他の$2$辺を記入せよ。
  5. $30^\circ,45^\circ,60^\circ$ について、$sin\theta,\ cos\theta$ の値を三角形の図から読み取り記入せよ。
  6. $30^\circ,45^\circ,60^\circ$ について、$tan\theta$ の値を三角形の図から読み取り記入せよ。

直角三角形の比

直角三角形について、以下の問いに答えよ。

  1. $30^\circ-60^\circ-90^\circ$ の直角三角形で、最も短い辺が$2$のとき、残り$2$辺の長さを求めよ。
  2. $30^\circ-60^\circ-90^\circ$ の直角三角形で、斜辺が$8$のとき、残り$2$辺の長さを求めよ。
  3. $45^\circ-45^\circ-90^\circ$ の直角三角形で、斜辺が$6\sqrt{2}$のとき、残り$2$辺の長さを求めよ。
  4. $60^\circ$ に対する向かい側の辺が$3\sqrt{3}$のとき、$30^\circ$ に対する向かい側の辺と斜辺を求めよ。
  5. $30^\circ$ に対する向かい側の辺が$5$のとき、$60^\circ$ に対する向かい側の辺と斜辺を求めよ。
  6. $45^\circ-45^\circ-90^\circ$ の直角三角形で、$1$辺が$4$のとき、もう$1$辺と斜辺を求めよ。

三角比

直角三角形において、角$\theta$に対する三角比を考える。

  1. $\cos 30^\circ,\ \cos 45^\circ,\ \cos 60^\circ$ の値を求めよ。
  2. $\sin 30^\circ,\ \sin 45^\circ,\ \sin 60^\circ$ の値を求めよ。
  3. $\tan 30^\circ,\ \tan 45^\circ,\ \tan 60^\circ$ の値を求めよ。
  4. 斜辺が$8$、$\theta=30^\circ$ のとき、底辺と高さを求めよ。
  5. 斜辺が$10$、$\theta=60^\circ$ のとき、底辺と高さを求めよ。
  6. 底辺が$6$、$\theta=45^\circ$ のとき、斜辺と高さを求めよ。

ラジアン

度数法と弧度法の変換、およびラジアンを用いた三角比の計算を行え。

  1. $30^\circ,\ 45^\circ,\ 60^\circ,\ 90^\circ$ をそれぞれ $[\mathrm{rad}]$ で表せ。
  2. $\displaystyle \frac{\pi}{6},\ \frac{\pi}{4},\ \frac{\pi}{3},\ \frac{\pi}{2}$ をそれぞれ度で表せ。
  3. $\displaystyle \cos \frac{\pi}{3},\ \sin \frac{\pi}{6},\ \tan \frac{\pi}{4}$ の値を求めよ。
  4. 斜辺が$8$、$\displaystyle \theta=\frac{\pi}{6}$ のとき、底辺と高さを求めよ。
  5. 斜辺が$4$、$\displaystyle \theta=\frac{\pi}{4}$ のとき、底辺と高さを求めよ。
  6. 底辺が$3$、$\displaystyle \theta=\frac{\pi}{3}$ のとき、斜辺と高さを求めよ。

三角比の総合

  1. $\theta=30^\circ$ のとき、$\sin\theta+\cos\theta$ の値を求めよ。
  2. $\theta=45^\circ$ のとき、$\sin\theta\cos\theta$ の値を求めよ。
  3. $\theta=60^\circ$ のとき、$\tan\theta\cos\theta$ の値を求めよ。
  4. $\displaystyle \theta=\frac{\pi}{6}$ のとき、$2\cos\theta+4\sin\theta$ の値を求めよ。
  5. $\displaystyle \theta=\frac{\pi}{4}$ のとき、$\displaystyle \frac{\sin\theta}{\cos\theta}$ の値を求めよ。
  6. $\displaystyle \sin\theta=\frac{3}{5},\ 0\lt\theta\lt\frac{\pi}{2}$ のとき、$\cos\theta$ と $\tan\theta$ を求めよ。

覚えるべき三角形の図示 解答

  1. $30^\circ\text{-}60^\circ\text{-}90^\circ$ の辺比 $1:\sqrt{3}:2$
  2. $45^\circ\text{-}45^\circ\text{-}90^\circ$ の辺比 $1:1:\sqrt{2}$
  3. 最短辺$=1\Rightarrow (1,\sqrt{3},2)$
  4. 斜辺$\displaystyle =1\Rightarrow \left(\frac{\sqrt{2}}{2},\frac{\sqrt{2}}{2},1\right)$
  5. $\displaystyle \sin30^\circ=\frac12,\ \cos30^\circ=\frac{\sqrt3}{2},\ \sin45^\circ=\cos45^\circ=\frac{\sqrt2}{2},\ \sin60^\circ=\frac{\sqrt3}{2},\ \cos60^\circ=\frac12$
  6. $\displaystyle \tan30^\circ=\frac{1}{\sqrt3},\ \tan45^\circ=1,\ \tan60^\circ=\sqrt3$

考え方

$\displaystyle \tan60^\circ=\frac{\text{対辺}}{\text{隣辺}}=\frac{\sqrt3}{1}=\sqrt3$
